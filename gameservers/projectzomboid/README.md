# Project Zomboid Server

This directory contains the configuration and scripts for running a Project Zomboid
dedicated server using BipOps.

Project Zomboid is a native 64-bit Linux dedicated server (Steam server appid `380870`,
store appid `108600`). It installs anonymously via SteamCMD and ships with its own bundled
JRE, launched through `start-server.sh`.

## Quickstart

```bash
docker run --rm -it --name bip-ops \
  -e BIPOPS_GAMESERVER=projectzomboid \
  -e PZ_SERVER_NAME="BipOps Project Zomboid Server" \
  -e PZ_ADMIN_PASSWORD="change-me" \
  -e PZ_PASSWORD="" \
  -e PZ_MEMORY=6144m \
  -p 16261:16261/udp \
  -p 16262:16262/udp \
  -v /path/to/gameservers/projectzomboid/game:/game \
  -v /path/to/gameservers/projectzomboid/backups:/backups \
  justmiles/bipops
```

## Required Ports

| Port  | Protocol | Description                                      |
| ----- | -------- | ------------------------------------------------ |
| 16261 | UDP      | Game port (DefaultPort) - server list + handshake |
| 16262 | UDP      | Client/direct connection port (UDPPort)          |
| 27015 | TCP      | RCON (only active when `PZ_RCON_PASSWORD` is set) |

Both UDP ports must be reachable for players to connect. RCON is optional.

## Volume Mounts

| Host Path                                  | Container Path | Description            |
| ------------------------------------------ | -------------- | ---------------------- |
| /path/to/gameservers/projectzomboid/game   | /game          | Game files directory   |
| /path/to/gameservers/projectzomboid/backups | /backups      | Backup files directory |

Server data (config, saves, logs) lives under `/game/Zomboid/` (pinned via
`-cachedir`), which is the backup source.

## Environment Variables

The server loads its config from `/game/Zomboid/Server/servertest.ini`, rendered from
the variables below. The sandbox ruleset (`servertest_SandboxVars.lua`) is generated by
the server on first boot using defaults and can be edited in place afterwards.

### Server Settings

| Variable               | Default                        | Description                                            |
| ---------------------- | ------------------------------ | ------------------------------------------------------ |
| PZ_SERVER_NAME         | BipOps Project Zomboid Server  | Public server name shown in the in-game browser        |
| PZ_SERVER_DESCRIPTION  | Hosted by BipOps               | Public server description                              |
| PZ_PUBLIC              | false                          | List the server in the public in-game server browser   |
| PZ_OPEN                | true                           | Allow players to join without being pre-whitelisted    |
| PZ_PASSWORD            | (empty)                        | Password required to join (empty = none)               |
| PZ_MAX_PLAYERS         | 16                             | Maximum concurrent players                             |
| PZ_PAUSE_EMPTY         | true                           | Pause world time when no players are online            |
| PZ_PVP                 | true                           | Enable player-vs-player combat                         |
| PZ_GLOBAL_CHAT         | true                           | Enable global (server-wide) chat                       |
| PZ_SPAWN_POINT         | 0,0,0                          | Forced spawn coordinates (0,0,0 = choose at spawn)     |
| PZ_MAP                 | Muldraugh, KY                  | Map(s) to load                                         |
| PZ_PING_LIMIT          | 400                            | Kick players above this ping (ms)                      |

### Admin & Security

| Variable                   | Default | Description                                                     |
| -------------------------- | ------- | --------------------------------------------------------------- |
| PZ_ADMIN_PASSWORD          | (empty) | Admin account password, applied when the admin user is created  |
| PZ_STEAM_VAC               | true    | Enable Steam VAC anti-cheat                                     |
| PZ_SAFETY_SYSTEM           | true    | Enable the PvP safety (duel/handshake) system                  |
| PZ_SHOW_SAFETY             | true    | Show the safety-mode indicator above players                   |
| PZ_AUTO_WHITELIST          | false   | Auto-add connecting users to the whitelist                     |
| PZ_DROP_WHITELIST_ON_DEATH | false   | Remove a user from the whitelist when their character dies     |

### Networking

| Variable     | Default | Description                                                 |
| ------------ | ------- | ----------------------------------------------------------- |
| PZ_GAME_PORT | 16261   | DefaultPort - UDP game/server-list port                     |
| PZ_UDP_PORT  | 16262   | UDPPort - UDP client/direct connection port                 |
| PZ_PUBLIC_IP | (empty) | Public IP announced to the server browser (auto if empty)   |
| PZ_RCON_PORT | 27015   | RCON TCP port (only active when a password is set)          |
| PZ_RCON_PASSWORD | (empty) | RCON password; RCON stays disabled while empty          |

### Mods

| Variable          | Default | Description                                               |
| ----------------- | ------- | -------------------------------------------------------- |
| PZ_MODS           | (empty) | Semicolon-separated Mod IDs to load                      |
| PZ_WORKSHOP_ITEMS | (empty) | Semicolon-separated Steam Workshop item IDs to download  |

### Performance

| Variable  | Default | Description                                                        |
| --------- | ------- | ----------------------------------------------------------------- |
| PZ_MEMORY | 4096m   | JVM max heap (`-Xmx`) written into `ProjectZomboid64.json`. Scale with the instance. |

## Server Administration

- The admin account is created on the first boot that `PZ_ADMIN_PASSWORD` is set.
  Changing it later is done in-game or via RCON, not by this variable.
- Enable RCON by setting `PZ_RCON_PASSWORD`; connect to TCP `27015` (or `PZ_RCON_PORT`).
- Set `PZ_MEMORY` to roughly match the host RAM (leave headroom for the OS). A heap
  that is too small will cause the server to stutter or crash with large maps/mods.

## Notes

- The server name is fixed to `servertest`, so its config and save data live at a known
  path (`/game/Zomboid/Server/servertest.ini`, `/game/Zomboid/Saves/`). Do not change it
  without updating `backupdir`/`configs` in `.bip-ops.yaml`.
- Workshop mods require the server to re-download content on boot when `PZ_WORKSHOP_ITEMS`
  changes; large mod lists increase startup time.
